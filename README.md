# Мои дела — PWA (задачи + заметки)

## Запуск
1. Залейте все файлы в репозиторий GitHub (в корень, без вложенных папок).
2. Settings → Pages → Source: Deploy from a branch → main → / (root) → Save.
3. Откройте ссылку вида https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПО/

## Установка на iPhone
1. Открыть ссылку в Safari.
2. «Поделиться» → «На экран “Домой”».
3. Открыть с иконки, добавить задачу — появится запрос на уведомления.

## Важно
- Данные хранятся в localStorage браузера устройства.
- На iOS уведомления работают с iOS 16.4+, только для установленной PWA в Safari.
- Уведомление о задаче приходит, когда приложение открыто или свёрнуто (без сервера фоновой доставки нет).
- Кнопка 🔔 в шапке — тестовое уведомление.

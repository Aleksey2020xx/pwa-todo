# Заметки — PWA

Простой todo-лист с уведомлениями. Работает как Progressive Web App (PWA).

## Как запустить

1. Залейте файлы на GitHub Pages (или любой статический хостинг).
2. Откройте ссылку на iPhone в Safari.
3. Нажмите «Поделиться» → «На экран Домой».
4. Откройте с иконки на домашнем экране.
5. Добавьте задачу — приложение запросит разрешение на уведомления.

## Важно

- Уведомления работают только когда приложение открыто (или свёрнуто в фоне на короткое время).
- iOS ограничивает фоновую работу — если приложение полностью закрыто, уведомление может не прийти.
- Для постоянных фоновых уведомлений нужен сервер с Web Push (FCM).
- Требуется iOS 16.4+ для поддержки push в PWA.

## Файлы

- `index.html` — разметка
- `style.css` — стили
- `app.js` — логика приложения
- `sw.js` — Service Worker (кеширование, обработка уведомлений)
- `manifest.json` — манифест PWA
- `icon-192.png`, `icon-512.png` — иконки

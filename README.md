# Задачи — PWA todo-лист с напоминаниями

## Как задеплоить
1. Все файлы — в корень репозитория GitHub.
2. Settings → Pages → Deploy from branch → main → /(root) → Save.
3. Ссылка вида https://логин.github.io/имя-репозитория/

## Как установить на телефон
1. Открыть ссылку в Safari (iPhone) или Chrome (Android).
2. iPhone: «Поделиться» → «На экран Домой». Android: меню → «Установить приложение».
3. Открыть с иконки, добавить задачу — разрешить уведомления.
4. Кнопка 🔔 в шапке отправляет тестовое уведомление — удобно для проверки.

## Важно
- Уведомления гарантированно приходят, пока приложение открыто или свёрнуто.
  Проверка времени тикает каждые 15 секунд, плюс срабатывает при возврате в приложение.
- Если приложение закрыто полностью — без сервера уведомление не придёт
  (ограничение мобильных браузеров).
- Яндекс.Браузер может не поддерживать уведомления для сайтов — для проверки
  используйте Chrome (Android) или Safari (iPhone, iOS 16.4+).

# Заметки и задачи (PWA)

Минималистичное веб-приложение: задачи с напоминаниями, заметки с тегами.

## Возможности
- **Задачи** — текст, дата и время напоминания. При наступлении времени — системное уведомление + назойливый баннер с вибрацией (пока приложение открыто).
- **Заметки** — растущее поле ввода, теги, список с превью.
- **Теги** — отдельный раздел с аккордеоном по тегам, группировкой по датам; фильтры по тегам в разделах.
- Все данные хранятся в localStorage браузера.

## Запуск
Залейте файлы в репозиторий и включите GitHub Pages (Settings → Pages → Deploy from branch → main → /root).

## Установка на iPhone
1. Откройте ссылку в Safari.
2. Поделиться → «На экран «Домой»».
3. Открывайте приложение с иконки.
4. Добавьте задачу — подтвердите разрешение на уведомления.

## Ограничения
Без сервера уведомления приходят, только пока приложение открыто или свёрнуто.
Для фоновых уведомлений нужна серверная часть (Web Push).
